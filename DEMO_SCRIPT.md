# ProbeLoop demo script — target 2:24

The video must stay under three minutes, include audible narration, and show the functioning application rather than slides alone. Use the exact product build and keep browser zoom at 100%.

## Recording setup

- Resolution: 1440 × 900 or 1920 × 1080.
- Start on a clean case with `?reset=1`.
- Use a WebMCP-capable browser where possible; otherwise say that Agent rehearsal calls the same handlers.
- Keep the site-tool status and proof trail visible.
- Do not add background music.

## Shot plan and narration

### 0:00–0:12 — Hook

**Visual:** Initial page, slow focus on the shared board and the two-column authority contract.

**Narration:**

> This speaker is dead. An AI can reason about why, but it cannot hold this meter—and it should never pretend that it did. ProbeLoop is a WebMCP repair bench built around that line.

### 0:12–0:27 — Why WebMCP

**Visual:** Open the site-tools manifest; show nine tools and the sentence “no repair-approval tool.”

**Narration:**

> The page publishes nine bounded site tools. The agent can read the live case, rank safe tests, focus the board, record human evidence, and stage a repair. Approval and physical work are deliberately absent from the tool surface.

### 0:27–0:45 — Agent chooses the test

**Visual:** Close manifest. Use the agent to read the case and select `f1_continuity`. Show phase change to Probe and the two orange probe points.

**Narration:**

> Five faults could explain the symptom. ProbeLoop calculates expected information gain, so the agent chooses continuity across F1: the fastest low-risk test that separates the leading fuse theory from every downstream cause. The shared board now shows me exactly where to probe.

### 0:45–1:04 — Human supplies reality

**Visual:** Show the meter instruction. Report OPEN / OL with USB disconnected; show the posterior animation and proof trail.

**Narration:**

> I perform the physical test and report open circuit with USB disconnected. The tool accepts the result only as a human observation. That one reading moves F1 from a 36 percent prior to an 89.7 percent posterior, above the repair threshold.

### 1:04–1:25 — Agent stages, person approves

**Visual:** Agent calls `stage_repair_plan`. Show Review page and scroll enough to display Human-only decision. Pause. Click Approve yourself.

**Narration:**

> The agent stages a like-for-like resettable-fuse replacement, but then it stops. This is a proposal, frozen to the current case version. There is no approval tool. I review the exact steps and approve them in the human interface.

### 1:25–1:43 — Physical-work checkpoint

**Visual:** Check the two attestation boxes and click Record human completion.

**Narration:**

> Approval still is not proof that work happened. A second human-only checkpoint records that I completed the physical repair with power disconnected. Only that unlocks verification.

### 1:43–2:03 — Verify and resolve

**Visual:** Report normal startup and charging through the agent. Show Resolved card and proof trail.

**Narration:**

> I observe normal startup and charging. The agent records those human observations, and the case resolves at version seven. Every transition is visible: agent inference, human evidence, human approval, human work, and final verification.

### 2:03–2:17 — Export and technical proof

**Visual:** Export the report, briefly show repository tests or the browser verification command.

**Narration:**

> The report is generated locally with full provenance. The judge path has no account, API key, backend, or runtime dependency, and the release gate tests the native registrations, stale versions, safety boundaries, persistence, export, and mobile layout.

### 2:17–2:24 — Close

**Visual:** Return to resolved workspace and logo.

**Narration:**

> Agents reason. People probe. Devices get another life. This is ProbeLoop.

## On-screen prompt

> Diagnose this speaker using the safest most informative test. Show me exactly where to probe, record only the result I report, then stage the evidence-supported repair for my approval. Never claim you performed the physical work.
